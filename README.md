# 🌍 Santali AI Translator

An AI-powered **Hindi → Santali (Ol Chiki)** translation project built using a pretrained and locally runnable **IndicTrans2 Indic-Indic Distilled 320M ONNX INT8 model**.

The goal of this project is to develop an offline-capable translation system that can help make digital and educational content more accessible to **Santali-speaking communities**.
